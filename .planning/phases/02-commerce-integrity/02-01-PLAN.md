# Plan 02-01: Subscription Creation and Order Integrity

## Goal

Expose the recurring product format at the start of course creation and stop dropping available financial/authorization fields when mapping orders.

## Requirements

- COM-01
- COM-02
- COM-03

## Tasks

1. Add failing tests for monthly/yearly subscription creation and free-course routing.
2. Add a domain-level product-format/billing-interval mapping.
3. Route paid drafts to Pricing and free drafts to Curriculum.
4. Add a failing complete-row mapper test and preserve all available order fields.
5. Run focused and full gates, inspect desktop/mobile behavior, update graph, and publish preview.

## Non-goals

- New database entities.
- Recurring invoice materialization.
- Advanced trial, dunning, multi-offer, coupon, affiliate, or tax behavior.
